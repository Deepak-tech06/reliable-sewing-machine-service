# Reliable Sewing Machine Mechanic Services

A modern showcase website for a sewing machine mechanic's services, allowing customers to explore services (repairs, new & second-hand machines, doorstep service) and connect via direct call or WhatsApp.

## 🚀 Features

- **Doorstep & Workshop Services**: Covers domestic, electric, and industrial sewing machines.
- **Service Listings**: Detailed cards for repairs, new machine sales, second-hand options, and home delivery.
- **Direct Contact & Urgent CTA**: Direct call dialing (`tel:`) and one-click WhatsApp chat integration.
- **Service Location Map**: Interactive embed pinpointing the service workshop.
- **Responsive & Modern UI**: Built with React, Tailwind CSS, Lucide icons, and dark/light theme support.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, TanStack Router & React Query, Lucide Icons
- **Backend**: Motoko (Internet Computer Canister) with local mock fallback

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Deepak-tech06/reliable-sewing-machine-service.git
   cd reliable-sewing-machine-service
   ```

2. **Install frontend dependencies:**
   ```bash
   cd frontend
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
